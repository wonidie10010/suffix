# v2.3 相对 v2.2.2(2) 的关键核心更新

资料口径：依据 `方法描述/v2.2.1/3检查点诊断/设计5/下一轮改动.md`，以独立 v2.3 sidecar、配置和本地验证产物为准。连续 Stage-1 与 R 的优化核从 v2.2.2(2) 复制；旧方法文件和独立配置保持原样。本报告记录实现与本地检查，正确率提升尚需完整实验验证。

## 1. 发现了什么问题

v2.2.2(2) 每次离散化沿用“两处轨迹各补一个、四类变体各补一个”的规则，种子扫描未优先采用统一基础表的高分合格项。v2.3 将轨迹采样、基础候选评分和种子变体生成按位置组织起来，并保留每次试算的来源与提交状态。

## 2. 做了哪些改动

| 环节 | v2.3 实现与默认配置 |
|---|---|
| 固定步号采样 | Stage-1：500/600/700/800/900；R：30/40；每处只取 Top1，严格剔除实际终点 |
| 基础表 B | 原 TopK → PPL TopK 稳定按 ID 去重，再追加过滤后的轨迹；初始最多新增 5，R 最多新增 2 |
| 评分与种子 | B 统一使用目标层 FP32 hidden 余弦；先做合法性、ASCII、精确单 token 往返和有限分数筛选，再取最多 5 个高分种子 |
| 变体表 M | 按大小写、字面前导空格、字符前缀、字符后缀扫描，配额为 3/3/1/3；每种子每类最多贡献一个新 ID |
| 复用与并列 | B 每个唯一 ID 只评分一次，再只评分 M；严格高分才替换 B 最优项；相同分数保持首次顺序 |
| R 事务 | 两次样本预算、每位置一次、50 步、lr=0.03；仅连续 hidden_loss 有限且严格下降时同步提交 embedding、tokens 和文本，否则整体回滚 |
| 结果记录 | 逐位置来源、快照、种子排序、过滤理由、配额缺口、分数、前缀指纹和计算量写入 `reconstructions.jsonl`；分别标记阶段产生、被接受、最终保留 |

默认 Top10/PPL10 下，候选上限为初始 35、R 32；绝对位置 0 无前缀时不调用 PPL，上限分别为 25、22。B0 保留原候选集合，新增项的过滤与种子往返要求不扩展到 B0。

新增 `suffix_reoptimization_v2_3.py` 和 `suffix_reoptimization_v2_3.json`，参数使用 `suffix_v2_3_*` 前缀；总配置登记新配置，`invert.py` 支持 `suffix_version=v2.3`。独立运行入口配置为 `experiment_configs/l24_deml3x4_suffix_v2_3.json`。现有默认 selector 保持原值，旧版仍可显式选择。

共享快照写入时同时采集旧版两处 Top10 与新五处 Top1，分别保存；旧版读取原 `stage_candidates`，v2.3 读取自身分组。仅有旧两处轨迹的历史快照会明确报错，要求重新采集。R 只使用本次调用的 30/40 轨迹。

## 3. 为什么要做这些改动

更多固定采样点保留连续优化中曾接近的 token；Top1 过滤失败后不从更深近邻补位，使采样含义一致。统一评分后的合格高分种子用于生成变体，预期改善候选覆盖；该收益需要通过配对实验验证。分阶段提交和最终保留标记用于区分 R 试算、接受及后续覆盖，支持离线计算 GT 覆盖、修复与损伤。

候选上限增加会带来额外前向开销。记录分别包含 PPL、候选前向调用数、评分候选数、序列 token 处理量、Stage-1/R 前向、轨迹检索和耗时。共享快照写入的旧版轨迹检索单独记录；重用 Stage-1 时标明该阶段未在当前分支执行。

## 4. 改动后的实验效果

已完成 118 项新机制、旧版与接入回归测试，以及本地微型 Qwen 的完整命令入口检查。CLI 检查包含两条合成样本，分别使用无固定前缀和公共 BOS 前缀；Stage-1 实际运行 901 步，五处轨迹均保留；R 实际运行 50 步，30/40 轨迹均保留。

实际核对了 `resolved_config.json`、`experiment.log` 和 `reconstructions.jsonl`：selector/参数、canonical 结果、`stage1`/`reoptimization` 分组、离线评估和严格 JSON 均可落盘。4 个 Python 文件通过 `py_compile`，3 个配置通过 JSON 解析，Git 差异检查通过；旧方法文件及独立配置的 SHA256 与任务开始时一致。日志保持固定的样本阶段与最终平均正确率摘要，没有生成 Excel。本地模型与验证结果按临时文件约定清理。

| 验证范围 | 结果 |
|---|---|
| 轨迹、种子、变体、并列、非有限分数、完整回滚与最终保留 | 通过本地测试 |
| 旧版回退、分组共享快照、selector 和主流程输出 | 通过本地测试 |
| 两条样本完整 CLI 与三个实际 artifact | 通过 |
| 正式数据集逐样本 accuracy、micro/macro 和相对提升 | 尚需完整实验验证 |

## 5. 后续改进方向

重新采集含两组轨迹的共享 Stage-1 快照，在固定模型、样本、TopK、ASCII 和 R 参数下比较 v2.2.2(2) 与 v2.3。分别统计轨迹和变体的新增覆盖、初始离散化、R 试算/接受、最终修复与损伤，并报告真实计算开销。可通过轨迹上限、种子数和四类配额开展消融。
