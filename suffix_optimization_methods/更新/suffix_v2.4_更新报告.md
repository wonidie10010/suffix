# v2.4 相对 v2.3 的关键核心更新

资料口径：依据 `方法描述/v2.4/3检查点诊断/设计1/下一轮改动.md`，以新 v2.4 程序、独立配置、单元测试和本地合成样本的 CLI artifact 为准。本文记录经代码确认的实现与本地验证；正式数据集效果尚需完整实验验证。

## 1. 发现了什么问题

v2.3 从左到右贪心离散化，前文一旦选定，后续位置沿该前缀生成 PPL 候选和 hidden 分数。当前位置出现接近的候选或整体拟合较差时，需要检查局部备选及最近前文对后续选择的影响。

## 2. 做了哪些改动

新增独立程序 `method_versions/suffix_reoptimization_v2_4.py` 和配置 `configs/suffix_reoptimization_v2_4.json`。v2.3 的 Stage-1/R 连续优化、Top1 轨迹、种子与变体生成基础保留；主流程支持 `suffix_version=v2.4`，实验入口配置为 `experiment_configs/l24_deml3x4_suffix_v2_4.json`。

| 环节 | 经代码确认的 v2.4 实现 |
|---|---|
| 异常触发 | 去重后的前两名分差小于 1e-3；最高分低于校准阈值时优先按低拟合处理；无第二名不计算分差 |
| 搜索范围 | 最多回退 2 位，每处最多 2 个备选，每路径主动改选一次，每事件最多 6 次试探；初始/R 分别保护 eval_start_pos/suffix_start 左界 |
| 备选来源 | 先取当前排序中的备选，再优先取同样本、同位置、同模型/词表的最近历史评分胜出 ID；保留被拒绝 R 的历史提案，重新评分 |
| 路径比较 | 原路径和试探统一延伸到 min(n−1,i+2)，比较 [max(a,i−2),r] 内真实离散 hidden 的半余弦距离之和；第一个严格超过接受容差的改善即提交 |
| 预算与恢复 | 每样本初始及全部 R 合计最多 2 个事件、额外前向暂取 64 次；调用前检查，按实际批次记录前向、评分候选及处理 token 量；中断保留完整原路径，失败和 R 回滚不返还预算 |
| 剪枝与状态 | 以非负部分误差之和作为下界；前缀变化后重建 PPL 并重评候选；试探及基准前瞻暂停触发，提交到 r 后从 r+1 继续；不保存试探缓存 |
| 结果记录 | 记录窗口、路径、历史来源、前缀指纹、误差、拒绝/剪枝理由及计算量，分别标记局部接受、R 接受与最终保留；离线统计覆盖、修复和损伤 |

总配置登记新版本，当前默认 selector 保持原值。v2.3 与 v2.2.2(2) 的程序和独立配置经 SHA256 核对保持一致，仍可显式选择。`experiment.log` 保持固定阶段摘要，明细写入 `reconstructions.jsonl`。

## 3. 为什么要做这些改动

有限回溯在异常处检查当前备选及最近前文。改变前缀后重新构建下游候选，可以评估新路径的实际选择；统一窗口和终点使各路径可直接比较。事件/前向预算、单次分叉和非负下界剪枝控制新增计算。R 仍以原连续 hidden_loss 条件接受整轮，局部路径改善与整轮提交分别记录。

低拟合阈值采用独立校准样本的最高分 5% 分位，无前缀首位单独分组；接受容差依据相同离散窗口的重复前向误差漂移及 FP32 精度余量冻结。程序提供 `collect_backtracking_calibration` 与 `build_backtracking_calibration`，校验样本身份、模型/词表、目标层及推理配置指纹，并记录校准来源与冻结校验值。

正式模型的校准尚未执行，独立配置中的拟合阈值、接受容差与校准元数据保留为空。缺少校准时以 `calibration_missing` 明确跳过回溯、保留原贪心路径。填入独立校准输出后启用完整搜索；设置 `suffix_v2_4_backtracking_enabled=false` 可做关闭回溯的对照。64 次前向预算仍需独立预跑确认。

## 4. 改动后的实验效果

| 验证范围 | 实际结果 |
|---|---|
| 本地单元与接入回归 | 111 项通过，其中 v2.4 针对性检查 24 项；覆盖边界、两位回退、最多六次试探、历史过滤与新增覆盖、前缀重评、固定窗口、数值容差、预算中断、禁止嵌套和 R 整轮回滚 |
| 实际 CLI | 微型 Qwen、两条合成样本，通过；分别覆盖无固定前缀与公共 BOS，Stage-1 901 步、R 50 步，使用另外两条合成样本冻结本地校准 |
| artifact | 已核对 resolved_config.json、experiment.log、reconstructions.jsonl；版本、校准参数、阶段分组、预算及离线归因可落盘，严格 JSON 可读，无新增 Excel |
| 语法与配置 | 新程序、主流程、输出模块及测试通过 py_compile；三个相关 JSON 通过解析；Git 差异检查通过 |
| 正式逐样本 accuracy、平均值和相对 v2.3 的提升 | 尚需完整实验验证 |

本地合成样本用于验证实现和落盘，不作为正式模型的校准或效果结果。对应临时模型与 artifact 按项目约定在任务结束前清理。

## 5. 后续改进方向

在正式模型和推理设置下，先用独立样本冻结两组拟合阈值、接受容差并校准额外预算，再固定上游输入、样本与 R 参数做回溯关闭/开启对照。核对真实 token 新增覆盖、修复、损伤、最终正确率、未触发错误、候选缺失和实际计算开销。
