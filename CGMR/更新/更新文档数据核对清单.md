# CGMR / Local 更新文档数据核对清单

## 1. 必查 artifact

每个 run 至少检查：

- `results/invert_timestamp_runs/<method_version>/<timestamp>/resolved_config.json`
- `results/invert_timestamp_runs/<method_version>/<timestamp>/experiment.log`
- `results/invert_timestamp_runs/<method_version>/<timestamp>/reconstructions.jsonl`
- 对应 `.xlsx` 汇总文件

## 2. 必查配置

- 数据集、模型、`num_invert_layers`、epoch 和运行时配置
- `selected_advanced_method` 与 suffix selector
- `selected_candidate_reranking_method` 与 CGMR selector
- CGMR 版本开关、配置层、实际有效层、权重和置信/接受阈值

## 3. 必算指标

- 上游方法最终 accuracy 与 CGMR 最终 accuracy
- CGMR 触发位置数、接受数、拒绝数和修改位置数
- 原错误位置修复数、原正确位置改错数和净 accuracy 变化
- 各层组合、候选数量、额外耗时和显存开销

## 4. 口径提醒

- suffix 内部 `pre_acc` / `post_acc` 与 CGMR 的 `pre_acc` / `post_acc` 分开汇报。
- selector 和 enable 开关必须从 `resolved_config.json` 确认，不能只根据文件夹名判断。
- Ground Truth 只允许用于离线统计，不得进入 CGMR 触发、评分或接受判断。
- 小样本只能写“初步迹象”，未完成实验时写“尚需完整实验验证”。
